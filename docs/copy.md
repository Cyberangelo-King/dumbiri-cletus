# Website Copy Document
## Dumbiri Cletus — Personal Brand Website

## Copy Philosophy

Every line on this site earns its place or it doesn't exist. The copy is confident, specific, and human. It reads like a brilliant friend giving advice — not a consultant on a retainer. No jargon. No hedging. No "I am passionate about helping clients achieve their goals."
