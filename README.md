# Dumbiri Cletus Personal Brand Website

Static frontend implementation of the dark, cinematic personal brand website design.

## Files

- `index.html` - semantic page structure and all major sections.
- `styles.css` - visual system, responsive layout, motion, and interaction states.
- `script.js` - menu overlay, content search/filtering, podcast switching, scroll reveal, and form helper behavior.

Open `index.html` directly in a browser to preview the site.
