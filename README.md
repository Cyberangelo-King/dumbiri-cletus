# Dumbiri Cletus — Personal Brand Website

A cinematic personal-brand website built for a public-facing creative identity.

## What the project demonstrates
This project is less about a static page and more about translating a person's identity into a coherent digital experience: information architecture, visual language, motion, content hierarchy, responsive behaviour and interaction.

## Repository structure
- index.html — semantic page structure
- styles.css — visual system and responsive behaviour
- script.js — navigation, search/filtering, podcast switching, reveal and form behaviour
- docs/ — research, requirements, brand, copy, design, motion and delivery decisions

## Build process
Discovery → identity model → content architecture → visual direction → interaction design → implementation → responsive refinement → QA → handoff.

The documentation is intentionally part of the project. It records why the site looks and behaves the way it does rather than presenting the final interface as if it appeared fully formed.

## Quality priorities
Semantic HTML, responsive layout, progressive enhancement, reduced-motion support, keyboard accessibility, fast initial load, no unnecessary dependencies, and content that remains understandable without animation.

## Status
Portfolio/client work. Final deployment and content should be validated against approved assets and production requirements.
